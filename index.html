AI · Automation
Job Apply Assistant — LLM-Powered Application Tool
GitHub

A local tool that parses a resume, pulls live remote-job listings, uses an LLM to tailor a resume and cover letter per posting, and auto-fills Greenhouse/Lever application forms for manual review.

  • Dual-engine LLM layer switchable between Google Gemini (cloud, structured JSON output) and Ollama (local, JSON-schema-constrained) behind one unified interface.
  • Prompt includes an explicit "honesty guardrail" instructing the model never to invent employers, titles, dates, or skills.
  • Aggregates listings from multiple remote-job feeds (RemoteOK, Arbeitnow, Jobicy, We Work Remotely) and ranks them by resume-keyword match.
  • Playwright drives a real, visible browser to auto-fill application forms, then leaves it open for the user to review and submit — no blind auto-submission.
